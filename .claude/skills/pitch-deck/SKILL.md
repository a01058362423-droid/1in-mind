# 피치덱 작성

1인 창업가가 투자자 또는 주요 고객/파트너에게 보여줄 피치덱의 슬라이드 구성과 각 슬라이드 문구 초안을 만든다.

## 대상에 따라 톤이 다름 (먼저 확인)

- **투자자용**: 시장 크기, 성장성, 팀(1인이라는 리스크를 어떻게 상쇄하는지), 유닛 이코노믹스 강조
- **고객/파트너용**: 시장 크기보다 "이 제품이 당신에게 어떤 결과를 주는지"와 신뢰 요소 강조

## 표준 슬라이드 순서 (투자자용, 10~12장)

1. 커버 (제품명 + 한 줄 소개)
2. 문제 (구체적, 감정적으로 와닿게)
3. 해결책
4. 제품 데모/스크린샷 설명
5. 시장 크기 (탑다운이 아니라 바텀업 계산 우선)
6. 비즈니스 모델 (수익 구조)
7. 트랙션 (숫자가 없으면 "검증된 신호" — 인터뷰, 대기자 명단, LOI 등으로 대체)
8. 경쟁/대안 비교
9. 고투마켓(GTM) 전략
10. 팀 (1인이면 왜 혼자서도 가능한지 — 도메인 전문성, 이미 만든 것 등으로 신뢰 보강)
11. 재무 요약 (허황된 숫자보다 가정을 명시한 현실적 추정)
12. 요청사항 (투자 규모, 용도)

## 작성 원칙

- 슬라이드당 핵심 메시지 1개, 문장은 짧게. 슬라이드는 "말하는 스크립트"가 아니라 "보여주는 것"이므로 발표자 노트와 슬라이드 텍스트를 분리해서 제시한다.
- 숫자를 지어내지 않는다. 근거 없는 숫자가 필요한 자리에는 "[여기에 실제 데이터 입력]" 같은 플레이스홀더와 어떤 데이터가 필요한지 표시한다.
- 요청 시 슬라이드별로 (제목 / 핵심 메시지 / 본문 텍스트 / 발표자 노트) 형식으로 출력한다.
